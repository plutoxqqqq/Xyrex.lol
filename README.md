# Xyrex.lol

**Xyrex.lol** is an executor and script hub. It lists executors with their pricing, official links, features, and live status, and it hosts a searchable library of Roblox scripts. It aims to help users compare options and discover trustworthy details about your favorite executors!

> https://xyrex.lol

---

## 🚀 Overview

**Executor directory** — executor data in a searchable and filterable format:

- Executor names, pricing tiers (free, paid, or both), and official links
- Stability, trust level, and sUNC scores
- Live status pulled from the WEAO feed
- Filters for platform, tags, cheat type, key system, price, and live status
- Sorting by name, sUNC, trust, or price
- Smart Rankings and a side-by-side comparison table
- Exploit Assistant!

**Script Library** — copy-ready scripts with the context you need before running one:

- Search across names, games, descriptions, tags, and features
- Filters for favorites, working status, key system, price, platform, and sUNC requirement
- A detail view per script with the full loader, a copy button, and a shareable link
- Compatibility matching that names which listed executors clear a script's sUNC requirement
- Favorites and a personal Saved Scripts store with JSON export/import, kept in your browser

Xyrex helps users compare tools without jumping between multiple sites.

---

## 🧩 Adding scripts

Scripts live in [`data/popular-scripts.js`](data/popular-scripts.js). Add an entry and it shows up on the site — categories are derived from the `category` field, so a new game appears the moment its first script is added. The header comment in that file documents the non-obvious fields.
